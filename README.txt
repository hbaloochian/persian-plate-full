api_endpoints.template.json قالب پیکربندی URL و auth

مواردی که عمداً حدس زده نشده‌اند:
- URL/path/schema و احراز هویت واقعی APIها؛ باید از مالک سرویس دریافت شوند.
- ترتیب معنایی شش خروجی ONNX باید با فایل باینری و اجرای مرجع تأیید شود.
- آستانه‌های عددی FPS/latency/RAM باید پس از benchmark تصویب شوند.
- مجوز تجاری مخزن، وزن‌ها و datasetها باید جداگانه بررسی شود.

امنیت: secret، token، password، کلید پشتیبان و keystore را در JSON یا Git قرار ندهید. از Android Keystore و GitHub Secrets استفاده کنید.

تصمیم تکمیلی: تصویر crop تشخیص در فرم تخلف به‌صورت پیش‌فرض انتخاب‌شده و همراه تخلف ذخیره می‌شود؛ مأمور می‌تواند پیش از ثبت نهایی انتخاب را لغو کند. این تصویر جزو سقف دو تصویر مجاز هر تخلف است.
